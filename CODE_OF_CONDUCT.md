# Code of Conduct

## Our Commitment

GEETA AI Engine is committed to creating a welcoming, professional, and respectful environment for everyone participating in the project.

We believe that open collaboration leads to better software. Every contributor should feel comfortable sharing ideas, asking questions, reporting issues, and participating in discussions.

---

# Expected Behavior

All contributors are expected to:

- Be respectful and professional.
- Welcome constructive feedback.
- Communicate clearly and respectfully.
- Help create a positive and collaborative environment.
- Respect different opinions and experiences.
- Focus discussions on improving the project.
- Report bugs and issues responsibly.
- Share knowledge with other contributors.

---

# Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment or discrimination of any kind.
- Personal attacks or insults.
- Offensive or abusive language.
- Threats or intimidation.
- Deliberate disruption of discussions.
- Publishing private or confidential information.
- Spam, trolling, or repeated off-topic discussions.
- Any behavior that creates an unsafe or hostile environment.

---

# Communication Guidelines

When participating in discussions:

- Stay respectful.
- Assume good intentions.
- Critique ideas, not people.
- Provide constructive suggestions.
- Keep technical discussions objective.
- Be patient with new contributors.

---

# Code Review Guidelines

Code reviews should focus on improving the project.

Review comments should:

- Explain the issue clearly.
- Suggest improvements where possible.
- Be respectful and professional.
- Avoid personal criticism.
- Reference project standards when applicable.

---

# Reporting Issues

If you experience or witness behavior that violates this Code of Conduct:

- Report the issue privately to the project maintainers.
- Include relevant details and supporting information.
- Avoid public arguments whenever possible.
- Allow maintainers time to investigate.

All reports will be handled respectfully and, where possible, confidentially.

---

# Enforcement

Project maintainers are responsible for enforcing this Code of Conduct.

Depending on the severity of a violation, maintainers may:

- Provide a warning.
- Request corrective action.
- Remove inappropriate content.
- Temporarily restrict participation.
- Permanently ban a contributor from the project.

Enforcement decisions will be made in the best interest of maintaining a healthy and productive community.

---

# Scope

This Code of Conduct applies to:

- GitHub Issues
- Pull Requests
- Discussions
- Documentation
- Project communication channels
- Any official project spaces

---

# Guiding Principles

GEETA AI Engine is built on the following values:

- Professionalism
- Respect
- Collaboration
- Integrity
- Transparency
- Continuous Learning
- Technical Excellence
