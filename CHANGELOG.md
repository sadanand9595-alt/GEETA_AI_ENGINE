## Versioning Strategy

GEETA AI Engine follows Semantic Versioning.

```
MAJOR.MINOR.PATCH

Example:

1.0.0

1.1.0

1.2.5

2.0.0
```

### MAJOR

Breaking architectural changes.

### MINOR

New features without breaking compatibility.

### PATCH

Bug fixes, documentation updates, and performance improvements.
